# Blackout Pub – Prenotazioni sala

Gestionale prenotazioni con assegnazione automatica dei tavoli, cambi tra i turni e avviso di overbooking.

- Sito: GitHub Pages (branch `main`, cartella principale)
- Dati e login: Firebase (Authentication Email/Password + Firestore)
- Configurazione: `firebase-config.js`
- Regole di sicurezza da incollare in Firestore → Regole: `firestore.rules`
- Utenti: crearli in Firebase → Authentication come `nome@blackout.app`; si accede scrivendo solo `nome`.
